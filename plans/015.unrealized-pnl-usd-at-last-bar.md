# 015 — plan

## Solution

In `getProfitStats` (`src/dca/strategy/main.ts`) convert each open deal's
`unPnl` with `getUsdRate(pair, markPrice)` and scale its usage with
`getRate({ symbol: pair, price: markPrice })`. `getRate` takes an optional
`at` and, when given, resolves its three rates through `getUsdRate` (the
existing helper realized profit already uses). Without `at` it is unchanged.
JIT tier 0: no extraction, two call sites.

## Blast radius

1. `getRate()` callers: the open-deal usage (changed, passes `at`) and
   `maxTheoreticalUsage` (unchanged, no `at`).
2. No `core/` submodule. Library consumed by main-app (server backtests) and
   main-dash-redesign (browser backtests); both need a lock bump to pick it up.
   One package, so server/client stay identical once both are bumped.
3. Result type unchanged; only values of `unrealized*` fields change when the
   reporting currency is not USD-pegged.
4. Golden fingerprint suites (`hooks-parity`, `file-mode-golden`, …): no
   fingerprint changes (USDT-quote scenarios, rate 1).
