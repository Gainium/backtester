position loop and run the existing per-deal loop for futures too. The `shared`
term passed to `replacePortfolioValue` keeps its futures value (coin-M → base,

1. Call sites: `checkPortfolio` is called from `checkDeals` only; `Strategy.position`
   is untouched (liquidation in `checkPosition` unchanged).
2. No `core/` submodule in this repo.
3. Contract: engine output (Danger List #13). Only `portfolio` and
   `maxDrawDownEquity*` change, and only for futures DCA/combo. Server-side
   (main-app backtest worker) and both dashboards must pick up the same version
   so their results stay identical.
4. Spot paths unchanged (diff is whitespace there: `git diff -w`).
