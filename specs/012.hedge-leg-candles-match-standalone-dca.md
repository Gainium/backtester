# 012 — A hedge leg trades differently from the same DCA bot on its own

Bug spec (Definition / Evidence / Assumption).

## §1 Definition

`HedgeBacktesting.test()` loads candles once for both legs, then splits them
per leg and runs each leg through `DCABacktesting`.

- **§1.1 Expected:** with the hedge TP/SL off, each leg opens and closes the
  same deals as a standalone `DCABacktesting` run of the same settings that
  loads its own candles.
- **§1.2 Actual:** a leg whose start condition reads a higher timeframe opens
  no deal until the indicator has warmed up inside the period, and a leg with
  more pairs than open-deal slots ignores the slot limit across pairs.

## §2 Evidence

- Replay with real exchange candles (Binance USDⓈ-M, 3 pairs, 15m short, RSI(7)
  15m cross-down OR group AND RSI(7) 1h/4h/1d level group, 2026-09-28 to
  2026-10-27, max 3 open deals / 1 per pair, hedge TP/SL off):
  standalone DCA 24 deals / +47.42; hedge short leg 10 deals / +19.84, no
  deal before 2026-10-11 (the standalone run has 15 before that date).
- Same replay with max 1 open deal: standalone 16 deals; with the warm-up
  restored but bars still grouped per pair, the leg books 24.
- `test/hedge-leg-warmup-parity.spec.ts` §1.1 fails on the old code, on a
  fix that restores only the time order, and on one that restores only the
  warm-up.

## §3 Assumption (root cause)

1. The per-leg split filtered every interval to `[period.from, period.to]`,
   dropping the `countBack` warm-up the DCA engine requests before
   `period.from` (`DCABacktesting.test` loads `from - countBack × interval`
   and lets `loadData(bars, startTime)` gate trading at the period start).
2. The split concatenated each pair's bars one pair after another. The DCA
   engine walks the lowest interval in array order, and `_loadData` returns
   bars sorted by time (then symbol), so the leg processed one pair's whole
   period before the next pair's first bar.

## §4 Blast radius

- Only `src/hedge/index.ts` (the loader-driven split). A host that passes
  `bars` to `test()` is unchanged.
- Hosts: main-dash-redesign runs hedge backtests client-side (only path; the
  server has no hedge variant). main-app does not import the hedge module.
- The hedge TP/SL branch reads the same split; its lowest-interval chunking
  assumes bars interleaved by time, which the sorted split now provides.
